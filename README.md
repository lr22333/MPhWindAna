# MPhWindAna

MATLAB-based toolbox for multiphase electrical machine winding analysis and visualization.

**MPhWindAna** is a MATLAB-based tool for the analysis and visualization of multiphase electrical machine windings. It is designed to calculate winding factors, analyze winding MMF and its spatial harmonics, and visualize winding layouts and slot-vector star diagrams.

The toolbox supports different stator slot numbers, pole-pair numbers, winding layers, winding sets, and phase numbers, making it suitable for the analysis of conventional and fractional-slot windings.

## Input Parameters

The main winding parameters can be specified through the following variables:

| Variable    | Description                      |
| ----------- | -------------------------------- |
| `NoS`     | Number of stator slots           |
| `NoPP`    | Number of pole pairs             |
| `NoWL`    | Number of winding layers         |
| `NoWS`    | Number of winding sets           |
| `NoPhPWS` | Number of phases per winding set |
| `WinP`    | Winding pitch in slots           |
| `HOmax`   | Maximum harmonic order           |

## Winding Factor Analysis

The function

```matlab
KdpwPlot
```

is used to calculate and visualize the winding factors.

The input argument determines which winding factor is displayed:

```matlab
KdpwPlot(1)
```

Distribution factor.

```matlab
KdpwPlot(2)
```

Pitch factor.

```matlab
KdpwPlot(3)
```

Winding factor.

Therefore:

| Input | Result              |
| ----: | ------------------- |
| `1` | Distribution factor |
| `2` | Pitch factor        |
| `3` | Winding factor      |

## MMF Analysis

### Winding MMF

The function

```matlab
MMFPlot
```

is used to calculate and plot the spatial distribution of the winding magnetomotive force (MMF).

```matlab
MMFPlot
```

The calculated MMF can be used to investigate the spatial characteristics of the winding.

### MMF Harmonics

The function

```matlab
MMFHarPlot
```

is used to analyze and visualize the harmonic components of the winding MMF.

```matlab
MMFHarPlot
```

The harmonic analysis is controlled by the parameter:

```matlab
HOmax
```

For example:

```matlab
HOmax = 30;
```

The harmonic orders up to the specified maximum harmonic order are analyzed.

## Winding Spatial Distribution

The function

```matlab
WindingPlot
```

visualizes the spatial distribution of the winding.

```matlab
WindingPlot
```

This plot can be used to inspect:

- Phase distribution
- Coil-side distribution
- Winding layers
- Winding sets
- Slot assignment
- Positive and negative coil sides

## Slot-Vector Star Diagram

The function

```matlab
SlotVectorPlot
```

plots the slot-vector star diagram based on the electrical position of the stator slots.

```matlab
SlotVectorPlot
```

The diagram is useful for investigating the spatial electrical distribution of stator slots and phase belts.

## Export Winding Data

The function

```matlab
exportWindingData
```

is provided to export the calculated winding data.

```matlab
exportWindingData
```

The exported data can be used for further analysis, documentation, or comparison with other winding-analysis tools.

## Main Functions

The main analysis, visualization, and data export functions are:

```matlab
KdpwPlot(1)
KdpwPlot(2)
KdpwPlot(3)
MMFPlot
MMFHarPlot(1)
MMFHarPlot(2)
WindingPlot
SlotVectorPlot
exportWindingData
```

## Supported Winding Configurations

The toolbox is intended to support a wide range of winding configurations, including:

- Three-phase windings
- Multiphase windings
- Single-layer windings
- Double-layer windings
- Single-set windings
- Multiple winding sets
- Integral-slot windings
- Fractional-slot windings

The actual range of valid configurations is subject to the parameter validation implemented in the MATLAB code.
